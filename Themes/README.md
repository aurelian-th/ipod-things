# Themes

RevisionOS uses `.rvt` theme files loaded by `appearance.rvx`.

## Installing themes

1. Ensure `Extensions/appearance.rvx` is copied to `/Revola/Extensions/` and enabled under **Settings > Extensions**.
2. Copy any custom `<theme>.rvt` files into `/Revola/Themes/` on your iPod.
3. Eject safely, then go to **Settings > Appearance > Theme** to switch themes, Dark Mode, Accent Color, and Menu Covers.

The built-in **Classic** theme (Light and Dark modes plus accent colors) is bundled directly inside `appearance.rvx`, so no separate `classic.rvt` file is needed in `/Revola/Themes/`. Any custom file named `classic.rvt` is ignored by Appearance.
