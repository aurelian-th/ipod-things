# Silent Remote Volume

Apple wakes the screen and resets the backlight timer whenever a wired headphone inline remote or dock remote sends Volume Up or Volume Down, even though headphone playback controls (double-tap and triple-tap) leave a dark screen dark.

With this extension enabled, volume button events from wired headphone inline remotes and dock/wired accessories change the volume without waking the screen or resetting the backlight timer. Disabling the extension restores Apple's wake behaviour at once.

| | |
|---|---|
| Default | off |
| Memory | image only |
| Settings | none |
| Minimum SDK | 1.74 |
