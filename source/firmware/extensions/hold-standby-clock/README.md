# Hold Standby Clock

Stock firmware updates the Hold icon immediately when Hold is engaged and waits about two minutes before showing the standby clock during playback. With this extension enabled, sliding Hold to locked jumps straight to Apple's standby clock while still following your Backlight Timer setting.

Unlocking Hold keeps Apple's behavior: the standby clock closes and the screen returns with the backlight on. Disabling the extension restores stock behavior at once.
